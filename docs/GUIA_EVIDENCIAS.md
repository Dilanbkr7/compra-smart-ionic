## Android (teléfono real)

- `capturas/icono-instalacion-android.jpg`: confirmación de instalación con ícono personalizado.
- `capturas/inicio-splash-android.png`: fotograma del arranque de la aplicación en Android.
- `capturas/compra-android.png`: pantalla Compra después de la bienvenida.

La evidencia acredita el ícono en la pantalla de instalación y el inicio visible en el teléfono. No se distingue inequívocamente el splash **nativo** de la bienvenida personalizada a partir de esta grabación; si se requiere demostrar ambos por separado, conviene iniciar una grabación antes de pulsar el ícono y abrir la aplicación en frío.

1. Entrar al repositorio en GitHub.
2. Confirmar que el README muestre las dos imágenes superiores.
3. Abrir el enlace `docs/video/inicio-android.mp4` y comprobar que se reproduce o descarga.
